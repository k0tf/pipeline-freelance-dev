# Pipeline Freelance Dev

Un vault [Obsidian](https://obsidian.md) gratuit pour aider les développeurs freelances à organiser leur prospection : savoir qui contacter, quand relancer et quoi écrire.

*English: a free Obsidian vault (in French) to track freelance developer prospects, follow-ups and outreach messages.*

## Ce que contient le vault

- **Tableau de bord** (plugin de base *Bases*) : prospects à relancer, pipeline par étape, suivi des propositions.
- **Modèles** : fiche prospect, fiche proposition, revue hebdomadaire.
- **Bibliothèque de messages** : 6 premiers contacts, relances à J+3 / J+7 / J+14, 6 réponses aux objections, messages de fin de mission.
- **Méthode** : définir son offre, routine d'environ 2 h par semaine, checklist avant envoi.

## Installation

1. Téléchargez le vault (onglet **Releases**, ou le dossier de ce dépôt) et dézippez-le.
2. Dans Obsidian : *Ouvrir un dossier comme coffre*, puis choisissez le dossier qui contient `00 - Commencer ici`.
3. Dans *Paramètres, Plugins de base* : activez **Modèles** et **Bases**.
4. Dans *Paramètres, Modèles* : réglez **Emplacement du dossier de modèles** sur `99 - Templates`.
5. Ouvrez `00 - Commencer ici` et suivez le guide.

Utilisez une version récente d'Obsidian. Le vault est conçu pour ordinateur.

## À savoir

C'est un outil de méthode et de suivi : il ne garantit aucun résultat. Les messages sont des modèles à personnaliser avant tout envoi.
